# fren
A Rust TUI tool like spf or yazi

It demark itself with a open feature letting you open files, directory with any app and being lighter

if you want to build it you can always clone it and cd to the dir and use 

`yay -S fren-git`

`makepkg -si`

have a nice day

if you have problems with emoji (as i had with kitty)
install your emoji icons for me it was

`sudo pacman -S noto-fonts-emoji`

add this to you shell

`export FREN_ICON_MODE=emoji`

add this in you terminal

`symbol_map U+1F300-U+1F9FF Noto Color Emoji`
